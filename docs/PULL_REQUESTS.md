# Live GitHub Pull Request Review in Ack

Ack enables live peer code review directly within developer chats and repository rooms.

### Features
- **Live Diff Fetching**: Fetches files and unified diffs directly from GitHub via REST API.
- **Privacy & Security**: Read-only access using standard login tokens; no broad `repo` write scope required.
- **Reference Sharing**: Shares repository and PR reference only; code is never stored in chat databases.
- **Large Diff Handling**: Large diffs and binary assets display a quick link to GitHub.
- **Private Team Comments**: In-line code comments are preserved securely in Ack.
